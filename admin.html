🔗 Referral Settings

Referral System

ON = referral tracking and eligible commission processing are enabled.

Commission Type

Fixed = ₦ amount per eligible commission. Percentage = percentage of Premium amount.

Premium Commission

Controls commission generated when a referred user receives their first Premium approval.

Renewal Commission

Renewal commission is generated only when this option is ON and the Premium request is identified as a renewal.


🗺️ Location Data Tools

Scans every user and product created before the State + LGA system, tries to match their old free-text "location" to one of the 37 states, and sets it as their new "state" field. LGA is set to "Not specified" since it cannot be determined from old data — sellers/admins should update it by hand afterwards.
